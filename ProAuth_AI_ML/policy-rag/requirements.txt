# Pinned to match the version ml/models/proauth_best_model.pkl was
# actually trained with. CORRECTION (2026-08-20): a prior pass here
# briefly re-pinned this to 1.9.0 on the mistaken assumption that matching
# requirements.txt to the (drifted) installed version would silence
# sklearn's InconsistentVersionWarning. Verified empirically that it does
# not — the warning compares the runtime sklearn version against the
# version *embedded in the pickle at save time* (1.8.0), which a
# requirements.txt edit can never change. Reverted to 1.8.0 and reinstalled
# it into the venv instead (see terminal history) — zero-risk fix, since it
# makes the runtime match what the artifact was actually trained with,
# rather than risking a subtly different predict_proba() from retraining
# or running a newer sklearn than the artifact was validated against.
